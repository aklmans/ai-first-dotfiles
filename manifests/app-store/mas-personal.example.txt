# Example App Store manifest.
#
# This is a format example, not the maintainer's paid/private app collection.
# It is never read automatically by bootstrap/app-store.sh.
#
# To use it as a starting point:
#
#   mkdir -p ~/.config/ai-first/software
#   cp manifests/app-store/mas-personal.example.txt ~/.config/ai-first/software/mas.txt
#   $EDITOR ~/.config/ai-first/software/mas.txt
#   ./bootstrap/app-store.sh --manifest ~/.config/ai-first/software/mas.txt
#
# Uncomment only apps you actually want and already own. Keep your list outside
# the repository. Copying an inventory is not choosing what to install.
#
# Format: <bundle id><TAB><display name>. Lines starting with # are ignored.
# `mas list` primarily reports numeric App Store IDs; these are NOT bundle IDs.
# Inspect the app's Contents/Info.plist CFBundleIdentifier for the value below.

# com.apple.iWork.Keynote	Keynote
