# App Store apps to install with `./bootstrap/app-store.sh`.
#
# Empty on purpose. Nothing in this repository depends on an App Store app, and
# a list of somebody else's paid, region-specific and vendor-utility software is
# not a sensible default to hand a stranger.
#
# Add your own, one per line:
#
#   <bundle id><TAB><display name>
#
# `mas list` reports numeric App Store IDs, not the bundle IDs used here.
# Read CFBundleIdentifier in the app's Contents/Info.plist. See
# mas-personal.example.txt for a worked example.
# Prefer a private list outside Git via `bootstrap/app-store.sh --manifest FILE`.
#
# bootstrap/app-store.sh shows you the full list and asks before installing
# anything, so an entry here is a proposal rather than an instruction.
